# Task Orbit

毎日のタスクを整理し、次にやることをくじで選べる日本語のタスク管理アプリです。HTML、CSS、JavaScriptだけで動きます。

## GitHub Pagesに置く

1. ZIPを解凍します。
2. GitHubでリポジトリを作り、解凍したファイルを `main` ブランチの一番上にアップロードします。リポジトリを開いて `index.html` が直下に見える状態にしてください。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** で **Deploy from a branch** を選び、ブランチを **main**、フォルダを **/(root)** にして **Save** を押します。
5. 公開が完了すると、同じページにサイトへのリンクが表示されます。

[GitHub公式の公開手順](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages)

`.nojekyll` はGitHub Pagesに静的ファイルをそのまま配信させるための空ファイルです。ビルドやAPIキーは不要です。

## 使い方

- **タスク追加**で期限、優先度、カテゴリ、タグ、所要時間、必要な集中力、メモ、チェックリストを設定できます。複数件の追加は入力欄の右のボタンから、1行に1件ずつ入力します。
- **今日**は今日までの未完了と今日の完了を表示します。期限なしのタスクは**すべて**から確認できます。**カレンダー**で日付を選ぶと、その日が期限のタスクが表示されます。
- **繰り返し**は毎日・毎週・毎月から選べます。チェックで完了にすると、次回分が未完了で追加されます。
- **タスクくじ**は、おまかせ・優先くじ・すきま時間・気分・3つ選ぶ・順番シャッフルの6種類です。対象は表示中の一覧とすべての未完了から選べます。すきま時間くじは所要時間を入力済みのタスクが対象です。優先くじは期限が今日までのものや優先度が高いものを引きやすくします。
- **タイマーにセット**を押すと、選んだタスク名が集中タイマーに表示されます。タイマーの分数は変更できます。タイマーはページを開いている間に使えます。
- **振り返り**では直近7日間の完了数を確認できます。初期サンプルは**設定・バックアップ → サンプルを消す**から削除できます。
- キーボードの **/** で検索、**N** でタスク追加を開けます。

## 端末・データ

タスク、カテゴリ、テーマは、同じ端末・ブラウザ内に自動保存されます。機種変更やPCとiPhoneの間でデータを移すときは、**設定・バックアップ**からJSONを書き出し、移行先で読み込んでください。読み込みは現在の一覧を置き換えます。

iPhoneやiPadでは、GitHub PagesのURLをSafariで開き、**共有 → ホーム画面に追加**でホーム画面から起動できます。公開ページをオンラインで読み込んだ後、キャッシュが作成されるとオフラインでも起動できます。
